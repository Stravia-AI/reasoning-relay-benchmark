# gate 任务：三段锁

工作区：`{{WORKSPACE}}`

你要在这个工作区里按顺序完成一条**依赖链**，最后把答案写进 `answer.txt`。每一步的输入都藏在
上一步的输出里，所以请**一次工具调用只做一步**，拿到输出后再决定下一步；不要猜路径，不要
并行试探。

## 步骤

1. 读 `work/start.txt`，取出其中的 `pointer`（一串十六进制）。
2. 算 `sha256(pointer)`，取前 16 个十六进制字符；用它拼出文件名
   `work/vault/<这16个字符>.txt` 并读出内容，得到 `code`（记作 C1）和 `route`（一个 lane 名）。
3. 读 `work/routes.json`，找到 `route` 对应的那一条，取出它的 `bin` 与 `salt`。
4. 读 `work/bins/<bin>.txt`，取出其中的 `check`（记作 C2）。
5. 算 `sha256("C1:C2:salt")` 的前 12 个十六进制字符，拼成最终答案
   `C1:C2:<这12个字符>`。

## 验收

- 在工作区根目录新建 `answer.txt`，**只写一行**，格式严格为
  `<C1>:<C2>:<12位十六进制>`，冒号分隔，前后不要空格，行尾可以有一个换行。
- 不要修改 `work/` 下的任何文件；除了 `answer.txt` 之外不要在工作区里留下别的文件。
- 完成后用一句话说明答案已写入，并把这行答案原样再打印一次。

注意：`work/vault/` 与 `work/bins/` 里有多个相似文件，只有按上面的顺序算出来的那个才属于本次
任务。
